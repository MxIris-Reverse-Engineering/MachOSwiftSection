# 0.20.0

## Breaking

- Some printed type names change, so ABI snapshots saved with 0.19.0 report those types as removed and re-added; regenerate your baselines.
- `MetadataReader` is renamed `SymbolicDemangler`, and `numUnderlyingTypeArugments` is renamed `numUnderlyingTypeArguments`; the old names stay deprecated for one release.
- Removed `PrimitiveTypeMapping` and `PrimitiveTypeMappingCache`.
- `FieldLayoutRenderable` no longer refines `MachOSwiftSectionRepresentableWithCache`; use `MachOFieldLayoutRenderable` where you need both.
- `HeapLocalVariableMetadata.captureDescription` is now a `CaptureDescriptor` instead of `String?`.
- Requires MachOKit 0.52.103, swift-demangling 0.7.1 and MachOObjCSection 0.8.106 or later, and adds a dependency on swift-capstone 6.

## New

- `swift-section objc` replaces `objc-section` with the same commands and output; the standalone `objc-section` is retired after this release.
- `dump` and `interface` now print types hidden behind accessor functions instead of `accessor function at 0x…`.
- `interface` recovers `@objc`, `@objc(selector:)`, `override` and `@objc @implementation` classes, even in stripped OS frameworks.
- `interface` prints property wrappers as `@Wrapper var x` and hides the synthesized `_x` and `$x`.
- New `--dependency-search-path` option tells `dump`, `interface` and `snapshot` where a binary's dependencies live.
- New `--infer-objc-overrides` option for `interface` also marks a method as `override` when only its selector name matches.
- Supports Swift 6.4 binaries, including `Builtin.Borrow` and `@_rawLayout` types.
- Private types in dyld caches keep their discriminator, so same-named private types no longer merge.
- New `SwiftThunkAnalysis` library product, and models for key paths, property descriptors, capture descriptors and accessible functions.

## Fixed

- Fixed `dump` and `interface` crashing intermittently on dylibs that declare no classes.
- Fixed `interface --parse-opaque-return-type` crashing with `Index out of range`.
- Fixed `interface` printing incomplete types such as `Predicate<>` and `init<>()`.
- Fixed wrong names for types in other modules' extensions, specialized generics and opaque result types.
- Fixed conformances to `private` protocols missing highlighting and links in semantic output.
- Fixed a type missing from the index when one of its methods has no implementation.
- Fixed a crash when indexing an image with a malformed symbol.
