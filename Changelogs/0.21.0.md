# 0.21.0

## Breaking

- ABI snapshots move to format version 6; regenerate baselines saved with 0.20.0.
- The library no longer clears its per-image caches under memory pressure; call `SharedCacheRegistry.shared.evictImagesWithoutLiveOwners()` (SPI) to free them.
- `SharedCache` (SPI) is now `final`; hold one and call `storage(in:)` instead of subclassing it.
- Requires MachOKitExtensions 0.1.2 and swift-capstone 6.0.1 or later.

## New

- `interface`, `diff`, `evolution` and snapshots now include class methods that stripped OS frameworks no longer name, such as those of `NSTableViewDiffableDataSource`.
- `interface` lists class methods in declaration order.
- Swift classes renamed for the Objective-C runtime now print with `@objc(Name)`.

## Fixed

- Fixed members of renamed classes losing `@objc` and `override`, printing as `final`, or showing slightly wrong field offsets.
- Fixed `init` and `init?` being mixed up for initializers that take a closure.
- Fixed wrong member and IMP addresses for in-process images outside the dyld shared cache.
