# 0.24.0

## Breaking

- `AccessorKind` gains `.borrowAccessor` and `.mutateAccessor`; exhaustive `switch`es must handle them.
- Reading APIs that take a Mach-O or a raw pointer now stay deprecated until 0.25.0 instead of 0.24.0.
- Requires swift-capstone 7.0.0 and MachOKitExtensions 1.3.0 or later.

## New

- New `--emit-private-source-files` option of `dump` and `interface`, and `emitsPrivateDeclarationSourceFiles` on their requests, names the source file of each private declaration.
- New `interface --requirements-on-associated-types` option, and `SwiftDeclarationPrintConfiguration.protocolRequirementPlacement`, writes protocol requirements on their associated types, as the compiler does.
- Supports Swift 6.4's `borrow` and `mutate` accessors and `~Copyable` associated types in `dump` and `interface`.
- New `CrossReferenceAnalysis` product finds the callers, callees and type references of functions in loaded arm64 images.
- A reader that wraps `MachOImage` or `MachOFile` is now read like the reader it wraps once it conforms to `MachOReaderWrapper`.

## Improved

- Offline layout comments now cover `Float16`, `StaticBigInt` and SIMD fields, `UnownedJob`, `UnownedSerialExecutor` and distributed actors with custom executors.

## Fixed

- Fixed protocol requirements printing the wrong type when their right-hand side is an optional or generic type.
- Fixed an extra tag byte in enum layouts with an `UnsafeContinuation` payload and two or more empty cases.
- Fixed a crash when reading a loaded image through a reader that wraps `MachOImage`.
