# 0.26.0

## Breaking

- Requires MachOKitExtensions 3.0.0 and MachOObjCSection 0.8.208.
- `SymbolLanguage.swift` now comes from `SwiftSymbols`; import it to compare a symbol's language with `.swift`.

## Improved

- MachOKitExtensions' C and C++ symbol index no longer mistakes an address in Swift code for the C function before it.
