# 0.25.0

## Breaking

- `MachOReading`, `MachOResolving`, `MachOPointers`, `MachOCaches`, `MachODependencies`, `MachOSymbols`, `MachOBase` and `MachOFoundation` moved to MachOKitExtensions 2.0.0; take those products from that package.
- The Swift symbol index moved from `MachOSymbols` to the new `SwiftSymbols` product, and `SymbolIndexStore` is now `SwiftSymbolIndexStore`.
- Removed the reading APIs that take a Mach-O or a raw pointer, `AsyncResolvable` and `ResilientWitness.implementationAddress(in: machO)`; pass `machO.context` or `.inProcess` instead.
- The Objective-C types of `SwiftInspection`, such as `ObjCMemberTable` and `ObjCClassHierarchyProviding`, moved to the new `SwiftObjCInterop` product.
- ABI snapshots now use format version 13; regenerate snapshots written by 0.24.0.
- `interface` and `dump` now write `any` before existential types; use `interface --no-existential-any` or `dump --disable-existential-any` to turn it off.
- `ExportStatus` gains `.declarationHasNoSymbol` and `.declarationIsCImported`; exhaustive `switch`es must handle them.
- `CodeReferenceTarget` and `CodeReferenceTable.Key` gain instance variable, C string and constant string cases; exhaustive `switch`es must handle them.
- Flag word kinds that can grow with the compiler, such as `MethodDescriptorFlags.kind` and `FunctionTypeFlags.convention`, are now optional.
- `ClassFlags` is now an option set, and `InvertibleProtocolKind`'s raw value is now a `UInt16`.
- Types conforming to `OpaqueTypeResolving` must implement `opaqueType(forNode:index:spellingOptions:)`.
- `AssociatedTypeWitnessProjection` is now `ResolvedAssociatedTypeWitness`, and `ConditionalWitnessCandidate` is now `ResolvedAssociatedTypeWitness.ConditionalCandidate`; the old names are deprecated.
- Requires MachOKitExtensions 2.0.0, MachOObjCSection 0.8.207, swift-demangling 0.7.4, MachOKit 0.55.102, swift-semantic-string 0.6.0 and FrameworkToolbox 0.17.0 or later.

## New

- New `swift-section refs` lists the code that references a selector, symbol, class, function, instance variable or string.
- New `swift-section symbolicate` tells what an unslid address is: a function, a stub, a pointer slot, a string or a symbol.
- `CrossReferenceAnalyzer` now reads a dyld shared cache file or standalone Mach-O files offline, through `init(dyldCache:)` and `init(machOFiles:)`.
- Cross references now include Objective-C instance variable accesses, C string and CFString literals, and the `route` each reference took.
- New `CrossReferenceAnalyzer.symbolication(of:)` tells what any address is.
- `dump` and `interface` now show `@objc` protocols declared in Swift and the Objective-C protocols Swift classes adopt.
- `interface` now prints `@Observable` classes as written in source; `interface --expand-macros` and `expandsMacros` print the expansion instead.
- New `printMacroExpansionParts(of:attachedTo:)` returns an `@Observable` expansion in the two levels Xcode shows.
- `dump`, `interface` and `diff` now include SE-0400 `init` accessors.
- New `objc interface --swift` and `ObjCInterfaceRequest.printsSwiftImport` print Objective-C classes, categories and protocols as Swift imports them.
- New `objc evolution --interface` merges versions into one annotated header, and `--emit-available` adds `API_AVAILABLE` / `API_OBSOLETED`.
- `ABIEvolutionBuilder.evolution(ofImageGroups:versions:)` and `AnySwiftEvolutionInterfaceBuilder` compare versions made of several images and report declarations that moved between them.
- New `SwiftDeclarationPrintConfiguration.marksCommentStructure` marks the kind and segments of each comment.
- `printExportedDeclarationsOnly` now works in marking mode, so a host can hide non-exported members from a search corpus printed once.

## Improved

- Reading Mach-O files and dyld shared cache images offline is much faster.
- `evolution` and `diff` no longer report members as removed in versions whose stripped symbols hide them.
- Cross references now count `objc_alloc_init`, `objc_opt_isKindOfClass` and similar libobjc calls as the sends they stand for.
- `dump` and `interface` now show members an optimized build kept only as an `@objc` thunk or an initializing entry point.
- `swift-section objc` now shows generic Swift classes and other Swift classes without a static class object.
- `interface` now shows members an image declares on another image's types, such as SwiftUI's on SwiftUICore types.

## Fixed

- Fixed `ExistentialTypeFlags.classConstraint` and `ProtocolDescriptorFlags.classConstraint` crashing, and `FunctionTypeFlags.convention` reading the wrong bits.
- Fixed a crash from running out of file descriptors when reading many images of a dyld shared cache.
- Fixed occasional crashes when several threads first read the same file or dyld shared cache image.
- Fixed constrained existential fields such as `any Boxed<Int>` printing as their argument type.
- Fixed opaque result types in Debug-built images printing a bare `some` or the wrong constraint.
- Fixed `interface --exported-only` keeping non-exported types of AppKit, and dropping C types with `--show-c-imported-types`.
- Fixed `swift-section objc` reading garbage method names from macOS 11 dyld shared caches.
- Fixed cross references missing calls in code rewritten by ld64 and misreading addresses on iOS devices.
- Fixed a crash in `CrossReferenceAnalysis` on a malformed export trie.
