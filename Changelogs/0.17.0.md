# 0.17.0

More of the original source recovered in `dump` / `interface` output, `__C` type names resolved to their real modules, and an N-version union interface. One breaking change.

## What's new

- **`final` is printed on class members.** It was never printed before, which was the one thing that made a hand-written `.swiftinterface` fail to link. The same change stops lazy `var`s printing their `Optional` storage type instead of the type callers actually see.
- **Duplicate extension blocks are gone.** The same `extension` block used to be emitted two or three times.
- **`--emit-header`** (`dump`, `interface`) — install name, UUID, architecture, file type, whether the binary was built with library evolution, and a note on what it provably cannot tell you.
- **`--emit-export-status`** (`dump`, `interface`) — marks members with no export-trie entry, so you can tell an API you can actually link against from one you cannot.
- **`--resolve-c-module-names`** (`interface`) — `__C.NSString` becomes `Foundation.NSString`. Requires Xcode; the first run per SDK generates and caches module interfaces (~30 s, ~10 s once cached). Add `--supplementary-apinotes` to supply your own mappings for frameworks with no SDK module at all, such as AttributeGraph.
- **`evolution --interface`** — renders N versions as a single Swift interface: every declaration appears once, with a trailing `// [●●○] removed in 26.0` where it changed and nothing where it did not. Every input must be a binary or dyld shared cache.

Every new annotation defaults to off.

## Fixes

- [#115](https://github.com/MxIris-Reverse-Engineering/MachOSwiftSection/issues/115) — `dump` mixed members up between same-named private types (SwiftUI's two `ArchivableDisplayList`s). Present since `0.14.0`.
- [#116](https://github.com/MxIris-Reverse-Engineering/MachOSwiftSection/issues/116) — `#pragma pack` C structs such as `__C.CMTime` lost every field offset to `0.16.0`'s foreign-struct guard.
- Opaque return types printed illegal Swift (`some Swift.Equatable<[A]>` — `Equatable` has no associated type).
- `diff --interface` double-indented accessor blocks.

## Breaking

`TypeNameResolvable.swiftName(forCName:)` is now `swiftName(forCName:category:)`. It has a default implementation, so a conformer left on the old spelling still **compiles and is silently never called**.

The build environment switches `MACHO_SWIFT_SECTION_USE_SPM_PREBUILD_VERSION`, `USE_CUSTOM_MACHOKIT`, `USE_CUSTOM_OBJC_SECTION` and `MACHO_SWIFT_SECTION_USE_SWIFTTUI` are removed.

## Other

- New library product `TypeIndexing` (macOS 13+), pulling in `SourceKitD` and `swift-apinotes`. All other pinned dependencies are unchanged from `0.16.0`.
- No snapshot `formatVersion` change.

## Requirements

- Swift 6.2+
- Xcode 26.0+
