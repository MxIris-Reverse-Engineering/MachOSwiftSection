# 0.22.0

## Breaking

- Reading APIs that take a Mach-O or a raw pointer are deprecated until 0.23.0; pass `machO.context` or `.inProcess` instead.
- The deprecated pointer reads throw `UnsafeRawPointer.Error.initFailed` on a null or tagged pointer instead of crashing, and return `.symbol` instead of trapping on a symbol reference.
- A custom `MachOBindRebaseResolving` type now has rebases applied to indirect pointers, so reads return the target instead of the raw fixup.
- `NamedDumpable` and `ConformedDumpable` requirements now take a `ReadingContext`.
- `ResilientWitness.implementationAddress(in:)` taking a Mach-O is renamed `implementationAddressString(in:)`.
- Requires MachOKit 0.54.101, MachOKitExtensions 1.1.2, MachOObjCSection 0.8.110, swift-semantic-string 0.4.0 and swift-syntax 602 or later.

## New

- New `SwiftSectionKit` library product runs every `swift-section` subcommand as a request; `dump` results carry each declaration's kind and name.
- New `--emit-available` option for `evolution --interface` prints a real `@available` attribute on each declaration, with `--platform` to override the inferred platform.
- New `SwiftDeclarationPrintConfiguration.marksOptionalContent` prints all option-controlled content once, marking which option shows each part.

## Improved

- Reading dyld shared caches split into many files, such as macOS 27's, is much faster and uses far less memory.
- An image read from a dyld shared cache now finds its dependencies in that same cache, so archived caches are laid out against their own frameworks.
- Swift subclasses of Objective-C classes in iOS 26 and earlier simulator runtimes now get their field offsets, `override` and ancestors.
- `private` and `lazy` stored properties of `@objc @implementation` classes now print their types.

## Fixed

- Fixed `swift-section objc` crashing on macOS 14.4–15.3.2 dyld shared caches and losing protocol method names on older ones.
- Fixed `evolution` crashing when the same build appears in two of the given dyld shared caches.
- Fixed wrong addresses, unnamed vtable entries and unread accessor-function types in main executables.
- Fixed static properties printing `Address: 0x0` in binaries that carry debug symbols.
- `swift-section objc` no longer aborts when its output stream is closed.
